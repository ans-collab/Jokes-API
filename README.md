# Jokes API

## What is Jokes-API?
A random joke generator


## URL

```
http://ec2.two-mites.com/api/jokes-api/random
```
 


## Tech Spec
Written in Java + Spring Boot;  CI/CD via Github Actions publishes to AWS EC2; Domain registered on CloudFlare
